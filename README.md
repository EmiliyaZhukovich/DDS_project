# ДДС (Django)

## Веб‑приложение для учёта движения денежных средств: создание, фильтрация, редактирование и удаление операций. Управление справочниками (статусы, типы, категории, подкатегории) через админ‑панель.

#### Стек
- Python 3.13+
- Django 5
- Django REST Framework (для JSON‑эндпоинтов зависимых списков)
- django‑filter
- SQLite
- Bootstrap 5 (CDN)

#### Установка и запуск
1) Клонирование репозитория
```bash
git clone https://github.com/EmiliyaZhukovich/DDS_project.git
cd dds
```
2) Виртуальное окружение и зависимости
```bash
poetry init
poetry install
poetry env activate
вывод предыдущей команды
```
3) Инициализация БД
```bash
python manage.py migrate
python manage.py createsuperuser  # для входа в /admin
```
4) Запуск сервера
```bash
python manage.py runserver
```
Откройте `http://127.0.0.1:8000/` — список операций. Админ‑панель: `http://127.0.0.1:8000/admin/`.

#### Использование
- Главная: таблица операций с фильтрами по дате, статусу, типу, категории и подкатегории.
- Создание/редактирование: форма с зависимыми списками. Подкатегории фильтруются по выбранной категории, категории — по типу.
- Справочники: добавляйте статусы, типы, категории и подкатегории в `/admin/`.

Бизнес‑правила и валидация
- Нельзя выбрать подкатегорию, не связанную с категорией.
- Нельзя выбрать категорию, не относящуюся к выбранному типу.
- Обязательные поля: сумма, тип, категория, подкатегория. Серверная валидация в `dds.models.Movement.clean`.

#### Структура
- `dds/models.py`: `Status`, `MovementType`, `Category`, `Subcategory`, `Movement`.
- `dds/views.py`: CRUD, список с фильтрами, JSON‑эндпоинты `api/categories`, `api/subcategories`.
- `templates/dds/`: `movement_list.html`, `movement_form.html` на Bootstrap.
- `dds/admin.py`: админка для справочников и операций.

#### Импорт стартовых данных (опционально)
Типы: Пополнение, Списание. Категории (для Списание): Маркетинг, Инфраструктура. Подкатегории: Farpost, Avito, VPS, Proxy. Статусы: Бизнес, Личное, Налог.

#### Развёртывание
SQLite по умолчанию. Для продакшена настройте `ALLOWED_HOSTS` и используйте внешнюю БД.
